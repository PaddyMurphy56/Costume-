3. **The record of your method research,** and why you chose what you chose.

5. **A handoff for Session 2:** what was built, how to use it, and what's unfinished or weak.
6. **The Session 2 kickoff prompt** in `docs/sessions/`, written from `docs/ROADMAP.md` and from what you actually built.
7. **Everything committed and pushed** on a branch with a pull request.

## Rules
- **Method first.** Start with a workflow that finds the best way to build this. Research tools, plug-ins, MCP servers and so on for the most efficient way to do everything. **Nothing is decided in advance,** including which web scraper to use.
- **Questions and suggestions.** During creation, ask the user 5–10 questions about how this should work, and suggest 1–5 things to implement.
- **Agents.** Create them whenever that would make the system better.
- **Scope.** Build only this part.
